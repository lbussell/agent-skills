# Never Block on the Human

Make reasonable decisions on reversible local work, proceed to the PR-ready review checkpoint, and let the user review the result.

- Complete reversible local work (writing and verifying code, running subagents, prototyping, and updating local notes) without stopping to ask for permission at each step.
- Explain the decisions you made when you present the result.
- When you find a local issue caused by your change, log it and fix it before presenting the result.
- Ask for explicit user confirmation before any irreversible, remote, or public action, including pushing commits, opening or merging pull requests, force-pushing, deleting data, or posting external comments.
- Ask the user when a product or preference decision cannot be settled by an experiment or existing repository conventions.
